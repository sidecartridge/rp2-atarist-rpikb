# Keyboard Layouts

The layouts in this directory are taken from Thorsten Otto's website: https://tho-otto.de/keyboards/ (Thank you! Great resource!)

The HID codes are taken from the USB HID Usage Tables: https://www.usb.org/sites/default/files/documents/hut1_21.pdf
